# KAI Personal — установщики

KAI — голосовой ИИ-помощник для Windows: отвечает на вопросы текстом и голосом,
по вашему подтверждению выполняет действия на компьютере, печатает под диктовку,
помнит то, что вы попросили запомнить, подсказывает погоду и рисует картинки.

В этом репозитории **только готовые установщики**. Исходного кода здесь нет.

## Скачать

Откройте раздел [Releases](https://github.com/AscGrey/KAI-releases/releases) и выберите один файл:

| Файл | Размер | Когда выбрать |
|---|---|---|
| `KAI-Personal-<версия>-WebSetup.exe` | около 2 МБ | Есть интернет. Установщик сам скачает KAI отсюда и проверит его. |
| `KAI-Personal-<версия>-Setup.exe` | около 270 МБ | Всё уже внутри: можно перенести на флешке и установить без интернета. |

Веб-установщик скачивает полный установщик того же выпуска и запускает его, только если
его контрольная сумма SHA-256 совпала с закреплённой. Иначе он ничего не устанавливает.

## Пробный период и ключ

* Без ключа KAI работает **3 дня** как пробная версия. В это время закрыты рисование картинок,
  диктовка и программирование; беседы, голос, действия на компьютере, погода и память работают.
* После пробного периода без ключа можно только читать, искать и сохранять прежние беседы.
* Ключ лицензии (`KAI1-…`) вводится в «Настройки → Лицензия» и проверяется на компьютере,
  без интернета. Ключ выдаёт продавец KAI.

## Проверить файл (по желанию)

Сравните результат с `SHA256SUMS.txt` из того же выпуска:

```powershell
Get-FileHash .\KAI-Personal-1.1.0-Setup.exe -Algorithm SHA256
```

## Требования

* Windows 10 или 11, 64-бит; права администратора не нужны.
* Интернет для ответов модели и ключ API Groq ([console.groq.com](https://console.groq.com)).
  Ключ вводится в окне KAI и хранится в диспетчере учётных данных Windows.
* Микрофон и колонки — по желанию.

## Предупреждение SmartScreen

Пока у установщиков нет цифровой подписи, Windows может показать «Система Windows защитила
ваш компьютер». Если файл скачан отсюда и контрольная сумма совпала, нажмите «Подробнее» →
«Выполнить в любом случае».
